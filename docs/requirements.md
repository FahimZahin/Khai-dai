# Project Requirements

## Restaurant Configuration

- 8 Tables
- 5 Chefs
- 2 Waiters
- 1 Manager role

## Customer Module

- Scan table QR code
- Browse food menu
- View ingredients
- View spice levels
- View allergens
- View preparation time
- Add food to cart
- Place orders
- Call waiter

## Manager Module

- Accept or reject orders
- Monitor orders
- Monitor tables

## Chef Module

- Receive assigned orders
- Prepare food
- Update food preparation status

## Waiter Module

- Receive service requests
- Handle customer requests
